# 🛡️ SOC Project — Sovereign Security Operations Center Design

**Context:** Academic group project (team of 5) — proposal for a sovereign Security Operations Center (SOC) for a strategic national energy and mining sector institution.

**My role:** Team lead, with strong hands-on involvement across all technical components (architecture, SIEM design, incident response procedures).

## Overview
Led a team of 5 in designing a complete SOC architecture proposal addressing IT/OT security supervision, regulatory compliance, and sovereign data hosting requirements for critical infrastructure protection.

## Key Components

### 🏗️ Architecture
- On-premise, sovereign SOC design (no public cloud dependency)
- SIEM solution: ELK Stack (Elasticsearch, Logstash, Kibana) + Wazuh
- IT/OT log integration (firewalls, servers, SCADA/PLC, Modbus, DNP3)
- Centralized security network with strict segmentation

### 🔍 SOC Operations
- Tiered analyst structure (N1 → N2 → N3, SOC Manager, CISO)
- Incident response playbook: Detection → Qualification → Investigation → Containment → Eradication → Recovery → Lessons Learned
- Alert correlation across IT and industrial (ICS/SCADA) environments

### ⚖️ Compliance & Governance
- Alignment with national data protection law (Loi n°2013-015)
- ISO/IEC 27001 best practices
- Critical infrastructure regulatory requirements

### 💰 Financial Proposal
- CAPEX/OPEX breakdown
- Two deployment models: autonomous SOC vs. managed SOC

## Skills Demonstrated
SOC design & leadership, SIEM architecture (ELK/Wazuh), IT/OT security, incident response procedures, regulatory compliance, technical writing, project coordination
