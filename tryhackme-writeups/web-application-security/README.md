## 2. Introduction

Web application security focuses on identifying and understanding vulnerabilities that affect web applications.

## 4. Key Concepts

### Web Application Vulnerabilities

Security weaknesses in web applications that may allow attackers to access sensitive information or perform unauthorized actions.

### SQL Injection (SQLi)

A vulnerability that occurs when an application improperly handles user input in database queries.

### Cross-Site Scripting (XSS)

A vulnerability that allows malicious scripts to execute in another user's browser through an application.

### Authentication and Access Control

Security mechanisms used to verify user identities and control access to application resources.
